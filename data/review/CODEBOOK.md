# Comparing two manifesto commitments

Read the earlier and later statement with their parent passages. The question is whether the same party undertakes the same action on the same policy instrument or for the same recognizable purpose at adjacent elections. Compare commitments expressed in the documents. A later government record of delivery is a different type of statement.

| Decision | Operational criterion |
|---|---|
| same | Both undertake the same material action. Reordering, synonymous names, equivalent units or a change from passive to active voice can preserve the commitment. |
| revised | Both describe an identifiable common commitment, and the text supplies a consequential change to the action, amount, duration, instrument, geography or beneficiary group. Mark the shortest informative old and new spans. |
| different | Different actions or instruments, shared issue only, or at least one statement is clearly descriptive rather than a commitment. |
| unclear | A fragment, ambiguous referent or missing policy detail prevents a reliable comparison. A detail omitted from a short restatement is insufficient by itself to establish a reversal. |

A currency amount that sets an income eligibility ceiling and one that sets an insurance benefit refer to different quantities. Compare their roles before treating a numeric difference as a revision. An announced past achievement and a new promise can use the same scheme name without making the same commitment. When a passage contains multiple actions, judge the main identifiable action of the selected span and use the parent to resolve references. Record ambiguity rather than manufacturing a match.

For retrieval, one or more earlier statements can match the same later pledge. Search the preceding same-party document by aliases, beneficiaries and action words, and inspect the pages. Record a previous ID only when it is a defensible same/revised relation. “No match located” describes the search performed. For a full human evaluation, review additional candidates beyond the automatic top five, check the PDFs for OCR misses, and keep candidate ranks and predictions hidden. Decisions supplied in this release are language-model judgments. The blank files are for a separate human review.
